World-Conquer

Build a base, harvest crystal and defeat the computer player. Everything you see is original placeholder art; the game runs entirely in this tab.

How to play
  1. Press Play, then choose Multiplayer and Skirmish.
  2. Pick a map and press OK.
  3. Select your mobile base and click it again to deploy it. Build from the sidebar on the right: power, a refinery, then barracks and a vehicle factory.
  4. Drag to select units, click to move or attack. Arrow keys or the screen edge scroll the map.
  5. Destroy every enemy building to win.

Engine diagnostics

Platform checks inside the real engine module. No game data is required. Each probe takes over the canvas; reload to switch modes.

The SDL2 probe animates a rectangle and logs mouse and keyboard input. The cooperative probe runs a synchronous C++ loop that yields to the browser through Asyncify.

The SHP diagnostic loads a project-owned sprite and palette from content/ and draws it with the engine's CC_Draw_Shape(). The wireframe diagnostic does the same for six placeholder shapes from wireframes/.

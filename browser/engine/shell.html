No game assets required. Select either probe (reload to switch modes). Click the canvas to change the moving rectangle's color. Press a key while the canvas is focused to log input. Reload to switch modes.

The original SHP diagnostic loads project-owned sprite and palette files from content/. It draws the sprite through the game's own tactical CC_Draw_Shape() into an offscreen buffer and presents that buffer with SDL2. It does not initialize a mission.

The wireframe roster diagnostic separately loads six verified, original-art placeholder SHPs from wireframes/, stages them in memory, then checks real C++ resource lookup and CC_Draw_Shape() for infantry, vehicle, aircraft, building, terrain and effect. Their final game-state frame layouts are not yet validated.

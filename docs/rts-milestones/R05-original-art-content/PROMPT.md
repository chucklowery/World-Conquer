# R05 — Original faction, unit, building, and map content

Implement **R05** in a clean context for `https://github.com/chucklowery/World-Conquer`. The native browser-playable Courier Extraction tactical alpha has a project-owned original-content pipeline under `game/content/` and `tools/content/`, with source SVG art, generated SHP/palette assets, HD cargo aircraft frames, and tests. The immersive HUD displays construction-card *previews*, not real buildable structures. See `docs/browser/CONTENT_PIPELINE.md`, `docs/browser/ART_FIRST_PASS.md`, `docs/browser/REPRESENTATIVE_FRAME_CONTRACTS.md`, `browser/engine/README.md`, `.github/workflows/browser-engine.yml`.

**Dependency gate:** none; R05 can run in **parallel with R00**, using current content naming conventions. Check `docs/rts-milestones/MANIFEST.md` first to avoid duplicate work. The future R00 entity/content interface is an integration consideration, not a prerequisite to beginning original art.

**Deliverable:** cohesive, legally distributable initial two-faction visual roster and metadata: infantry, harvester, combat vehicle, base hub, refinery, power plant, barracks, factory, resource tiles, terrain and tactical effects, with necessary facings/animation/health states. Extend source-driven build/validation tools, attribution and size budgets, and produce a reference gallery. No copied Command & Conquer logos, sprite sheets, or proprietary game data. Favor compact, recognizable silhouettes at gameplay zoom, correct unit-team coloring, and browser-friendly packing.

**Acceptance:** project-owned source files and attribution verified; all designated actors/buildings pass sprite/atlas/animation contracts; assets package in CI with deterministic manifests/hashes; an in-browser gallery or test scene shows both factions at real battlefield size, and the existing tactical alpha still starts. Coordinate IDs with the accepted simulation registry at merge time, without changing its semantics.

**Manifest protocol:** edit **only the R05 row** of `docs/rts-milestones/MANIFEST.md`: `in_progress` at start; `blocked` if blocked; `completed` only when validations, asset CI, browser gallery, and code review pass. Record PR, commit, test commands/results, CI and visual evidence; preserve other rows. Run `node docs/rts-milestones/validate-roadmap.js` and relevant `tools/content/test-*.js`/browser checks; create a scoped PR.

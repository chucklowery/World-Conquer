# Browser Port Backlog

The backlog is the milestone checklist in [`docs/ROADMAP.md`](../ROADMAP.md).
Each unchecked item there is one work package; larger milestones are split
into sessions under [`docs/milestones/`](../milestones/README.md).

GitHub Issues are disabled for this fork. If they are enabled later, create
one issue per unchecked roadmap item and link it from the roadmap.

The earlier BROW-001 to BROW-007 specifications (native baseline, SDL2 smoke,
Emscripten CMake, link blockers, cooperative lifecycle, local asset import,
first mission) were completed by M1–M3 or superseded by the original data
pack; they are in git history.
